## Installation:

You can get **homepage** running by:

1. download the source.
2. move it in a place you like.
3. select the index.html as your default "new tab" in your favorite browser.
4. done!

It's recommended to install the stable original version, [homepage](https://github.com/tuthbrush/homepage), rather than mine.
